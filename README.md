# 📺 IP-TV Player

Универсальный плеер для просмотра открытых (незашифрованных) потоков IP-телевидения.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-green)
![License](https://img.shields.io/badge/license-MIT-yellow)

## ✨ Возможности

- 📡 Просмотр потоков **HTTP, HLS (m3u8), RTMP, UDP**
- 📋 Переключение между **несколькими плейлистами** (M3U/M3U8)
- ⚙️ Индивидуальные настройки для каждого канала
- 🎬 **Запись потока** в файл (фоновая, неограниченное количество каналов)
- 📊 **OSD** — громкость, название канала, индикатор записи
- 📺 Список каналов в видео-окне
- ⌨️ Полное **управление с клавиатуры**
- 📅 Поддержка телепрограммы (**XMLTV, JTV, TXT**)
- ⏰ **Планировщик** записи/просмотра
- 📱 **Смартфон как пульт управления**

## 🖥️ Desktop-версия (Windows .exe)

### Быстрая сборка

```bash
# 1. Автоматическая настройка
node setup-electron.js

# 2. Сборка .exe
npm run electron:build
```

**Результат:** `release/IP-TV Player Setup 1.0.0.exe` (~80-120 MB)

📖 [Подробная инструкция](BUILD_WINDOWS.md)

### Предварительно собранные версии

Скачать готовые `.exe` можно на странице [Releases](../../releases) (после публикации).

## 🌐 Веб-версия

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Space` | Пауза / Воспроизведение |
| `↑` / `↓` | Громкость +/− |
| `←` / `→` | Предыдущий / Следующий канал |
| `M` | Вкл/Выкл звук |
| `F` | Полный экран |
| `L` | Список каналов |
| `E` | Телепрограмма |
| `R` | Запись |
| `I` | Показать OSD |
| `H` | Справка |
| `1-9` | Быстрый переход на канал |

## ⚠️ Важная информация

- Мы **не оказываем услуг IP-телевидения**
- Плеер для просмотра услуги **вашего провайдера** или открытых источников
- **Не предназначен** для просмотра российских каналов из-за границы
- **Не может** показывать зашифрованные (DRM, CAS, X-KEY) каналы

## 🛠️ Технологии

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS
- **Desktop:** Electron, electron-builder
- **Потоки:** hls.js, FFmpeg (Desktop)
- **Состояние:** Zustand
